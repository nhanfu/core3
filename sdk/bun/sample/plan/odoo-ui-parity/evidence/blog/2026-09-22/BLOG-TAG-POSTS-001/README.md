# BLOG-TAG-POSTS-001

Bounded Blog Tag reverse `post_ids` relation slice. This implements the Odoo
Blog Tag form's `Used in` posts relation using the existing durable
`blog_post_tags` table. It does not sign off the full Blog module.

Artifacts:

- `odoo-analysis.md`: local Odoo 19 source behavior and live-reference result.
- `menu-action-inventory.md`: action/menu/view binding for the slice.
- `functionality-checklist.md`: feature acceptance cases and results.
- `source-comparison.md`: Odoo/Core3 mapping and exact paths.
- `gap-matrix.md`: bounded gap and implementation mapping.
- `test-results.md`: focused and regression command results.
- `verification.md`: authenticated browser and visual-parity status.
- `browser-check.md`: BrowserSkill session result and exact blockers.
- `odoo-desktop-404.png`, `odoo-mobile-404.png`: blocker captures only.

No credentials, cookies, tokens, or secrets are stored here.
