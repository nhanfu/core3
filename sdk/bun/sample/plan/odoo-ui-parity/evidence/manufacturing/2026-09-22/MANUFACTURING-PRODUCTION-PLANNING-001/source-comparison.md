# Source comparison

Odoo’s action is a non-terminal-production Work Orders Planning view with five
view modes and default Ready/Blocked/In Progress filters grouped by
Manufacturing Order. Core3 now has the same action-level scope, default
selection, mode set, read-only list boundary, and existing operator workflow
guards. Core3’s shared Fluent shell and deterministic rows remain visual
differences that cannot be adjudicated without the authenticated Odoo capture.
