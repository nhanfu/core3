# Verification and residuals

The durable contract is verified by the focused and full Events integration
suites. The active list query returns ten active deterministic events and
excludes `event-archive-20260115`; the archived filter returns that fixture.
Archiving `OpenWood Collection Online Reveal` removes it from the default list,
increments its row version, and makes it visible in Archived. Restore returns
it to the active list and increments the version again. Reusing an old version
returns `EVENT_ARCHIVE_STALE`, and an unknown ID returns `EVENT_NOT_FOUND`.

The remaining gate is authenticated Odoo desktop/mobile comparison. BrowserSkill
borrow confirmation blocked that external evidence in this checkpoint, so the
feature and module remain conditionally open rather than visually signed off.
