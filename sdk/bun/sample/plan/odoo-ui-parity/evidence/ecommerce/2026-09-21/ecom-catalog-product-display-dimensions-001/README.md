# ECOM-CATALOG-PRODUCT-DISPLAY-DIMENSIONS-001

Wave 15 bounded Ecommerce parity evidence for Website Sale product display
dimensions. This slice covers durable `website_size_x`/`website_size_y`
product fields, Products/Shop/Product Detail page/API pairing, guarded CRUD,
deterministic fixtures, and restart persistence.

The slice is locally verified and committed without push. It is not Ecommerce
module sign-off: authenticated rendered Core3 desktop/mobile capture is blocked
by the unavailable browser runtime and local routes, while the supplied Odoo
`/shop` endpoint remains an exact HTTP 404.
