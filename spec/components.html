Usage

Importing components

All components are available from the barrel or from their individual file:

// Barrel — import any mix
import { GridView, FormPanel, StatRow, FilterBar } from '/lib/components.js';

// Individual file — explicit dependency
import { GridView }  from '/lib/components/GridView.js';
import { TextInput } from '/lib/components/TextInput.js';

Each component file only imports what it needs (html singleton, BaseComponent, helpers). Shared formatting utilities live in lib/components/helpers.js.

Form container

FormPanel

formlib/components/FormPanel.js

Owns a group of input components. Provides registerField(), collectValues(), validate(), and async submit(action, params) that validates first then calls root _onAction. Renders [data-form-fields] and [data-form-actions] slots.

const form = new FormPanel('truck-form', {}, { title: 'Truck Information' });
form.mount(container);

const fPlate = new TextInput('f-plate', { value: '' }, { label: 'Plate', field: 'plate', required: true });
form.registerField(fPlate);
fPlate.mount(container.querySelector('[data-form-fields]'));

await form.submit('truck.update', { id: truck.id });
StateTypeDescription
savingbooleanSpinner while submit is in flight
dirtybooleanTrue after any field change
valuesobjectCollected field values
errorsobjectField-level validation errors
Def propTypeDescription
title ?stringPanel heading
