Usage

Importing components

All components are available from the barrel or from their individual file:

// Barrel — import any mix
import { GridView, FormPanel, StatRow, FilterBar } from '/lib/components.js';

// Individual file — explicit dependency
import { GridView }  from '/lib/components/GridView.js';
import { TextInput } from '/lib/components/TextInput.js';

Each component file only imports what it needs (html singleton, BaseComponent, helpers). Shared formatting utilities live in lib/components/helpers.js.

Form container

FormPanel

form lib/components/FormPanel.js

Container that owns a group of input components. Provides registerField(), collectValues(), validate(), and an async submit(action, params) that validates then calls the root _onAction. Renders two named slots: [data-form-fields] and [data-form-actions].

const form = new FormPanel('truck-form', {}, { title: 'Truck Information' });
form.mount(container);
const slot = container.querySelector('[data-form-fields]');

const fPlate = new TextInput('f-plate', { value: '' }, { label: 'Plate', field: 'plate', required: true });
form.registerField(fPlate);
fPlate.mount(mkSlot(slot));

await form.submit('truck.update', { id: truck.id });
StateTypeDescription
savingbooleanShows spinner while async submit is in flight
dirtybooleanTrue after any field changes
valuesobjectCollected field values (via collectValues)
errorsobjectField-level validation errors
Def propTypeDescription
title ?stringPanel heading

StatRow

kpi lib/components/StatRow.js

Responsive grid of StatCards. Column count auto-selects from the number of stats (2→2-col, 3→3-col, 4→4-col).

new StatRow('fleet-stats', [
  { label: 'Total',       value: 42, color: 'indigo' },
  { label: 'Active',      value: 31, color: 'green', trend: 'up', delta: '+3 this month' },
  { label: 'Maintenance', value:  7, color: 'amber' },
  { label: 'Inactive',    value:  4, color: 'red' },
]).mount(document.getElementById('stat-row'));

Constructor: StatRow(id, stats[]) — stats is an array of StatCard state objects.

Layout

TabPanel

layout lib/components/TabPanel.js

Horizontal tab strip with a content area below. Each tab either runs a render(el) function or renders a raw HTML content string. Switching tabs calls setState({ active: i }) which redraws only the content slot.

new TabPanel('tabs', { active: 0 }, [
  { label: 'Trips',  render(el) { new GridView(...).mount(el); } },
  { label: 'Issues', render(el) { new GridView(...).mount(el); } },
  { label: 'Docs',   content: '<p>No documents yet</p>' },
]);
Tab entryTypeDescription
labelstringTab button text
render ?(el: HTMLElement) => voidMounts components into the content slot
content ?stringRaw HTML string (alternative to render)

FilterBar

control lib/components/FilterBar.js

Horizontal bar of filter controls. Supports three field types: select, search, and date-range. Every change calls submit('filter.change', { values }); the Clear button calls submit('filter.clear', {}).

const bar = new FilterBar('fleet-filter', { values: {} }, [
  { field: 'status', label: 'Status',   type: 'select', options: ['Active', 'Maintenance'] },
  { field: 'q',      label: 'Search',   type: 'search', placeholder: 'Plate or driver…' },
  { field: 'due',    label: 'Due Date', type: 'date-range' },
]);
bar._onAction = (action, params) => {
  if (action === 'filter.change') refreshGrid(params.values);
};

fieldstringKey in values object

type'select'|'search'|'date-range'Input type to render
options ?string[]Options list (select only)
placeholder ?stringPlaceholder text (search only)
