# CRM Dashboard Checklist

## Visible controls

- Period presets and custom date range refresh KPI, pipeline, and recent-quote sources.
- KPI cards show customer, employee, team, company, lead, accepted-quote, and approved-order metrics.
- Quote pipeline chart and recent quote grid are visible.
- CSV export and column chooser are available on the recent quote grid.

## Interaction checks

- Select each period preset and confirm all CRM sources refresh together.
- Set a custom date range and verify KPI counts and quote rows change.
- Export recent quotes and confirm the active date filter is represented.
- Hide/show a recent-quote column through the chooser.
