# Accounting Summary Checklist

## Visible controls

- Debit-note and payment-request summaries show period presets, custom dates, search, status tabs, exports, totals, status charts, and grouped grids.
- Both report grids support column chooser and preserve currency/status context.

## Interaction checks

- Switch between period presets and confirm totals, charts, and grouped rows refresh together.
- Select each lifecycle status and verify the grid and status chart reflect the selected period.
- Search by counterparty and export the filtered summary.
- Hide/show a summary column through the chooser.

- Payment-request desktop/tablet: `payment-requests-desktop.png`, `payment-requests-tablet.png`.
